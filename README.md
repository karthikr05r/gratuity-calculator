# Gratuity Calculator — Karthik 44110355

A responsive, beginner-friendly gratuity calculator built with HTML, CSS, and vanilla JavaScript. It can run locally in a browser and be published free with GitHub Pages.

## Features

- Monthly Basic + Dearness Allowance (DA) input
- Years of service and additional months
- Estimated gratuity calculation using the common formula
- Responsive layout for mobile and desktop
- No build tools or dependencies required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `karthik-44110355`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings.

## Calculation note

This demo estimates gratuity with the common formula:

`Last drawn monthly Basic + DA × 15 ÷ 26 × counted years of service`

Actual eligibility, service-period rounding, limits, and rules can differ depending on applicable law and employment circumstances. This project is for educational estimation only; check with HR or a qualified professional for an actual entitlement.
